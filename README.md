Verified marketplace / trust layer for secondary AI hardware (retired data-center GPUs).

Founder: Brady Schwartz. Status: pre-incorporation, strategy phase (June 2026).

## The thesis in one line

Trust is the scarce thing in the secondary AI-hardware market. Sabify sells **certainty — verification + certified wipe + warranty + clean provenance** — on used GPUs, starting as a consignment-first broker and growing into the owner of the physical-resale price index. Build the rails in the boom, buy the dip in the bust.

## The strategic call (see STRATEGY.md)

Be the **trust layer**, not an inventory dealer. Consignment-first brokerage + verification/escrow/NIST-wipe/provenance for small distressed-seller lots (8–64 GPUs). Building computers from used chips is a Phase-2, build-to-order-only add-on. Never touch China (export controls). Own the resale price index.
